# Optional public-page analytics

Set `VITE_GA_MEASUREMENT_ID=G-KB7KT8NJW8` for both the client build and web-service runtime. Without a valid ID, Plannix does not load Google Analytics. The runtime value permits the same-origin analytics frame in the main CSP and Google tag/GA4 endpoints only in that frame's CSP. The exact `/analytics-frame.js` bootstrap has a CORP exception so the opaque frame can load it; other static resources retain Helmet's normal resource policy. The ID is not a credential. Do not add an unconditional tag snippet to `index.html`.

In the GA4 web data stream, turn **Enhanced measurement off**, including history-based page views. Keep Google signals and advertising features off. Plannix disables the tag's automatic page view and sends only manual page views for signed-out visits to `/`, `/features` and `/contact` with no query string or fragment. URLs and titles are fixed, and referrers are limited to same-origin public routes. No login, signup, authenticated, callback or notification-reference page is tracked.

The existing cookie dialog asks for an explicit analytics choice. Older broad consent records do not authorize GA4. The Google script is requested only after acceptance on an eligible page, inside a hidden sandboxed frame with an opaque origin. The frame receives only validated public-page URLs, fixed titles and sanitized public referrers; it cannot read the application document, history, storage or authenticated content. It is destroyed on withdrawal or entry into an excluded scope, discarding pending work and its event listeners. Advertising consent remains denied. The footer's Cookie settings control permits withdrawal and attempts to remove this site's GA cookies. Requests already transmitted cannot be recalled, and Google tag behavior or browser restrictions may affect measurement. Analytics failures do not block the application.

The isolated frame cannot use the application's first-party cookies, so GA4 counts and visitor continuity may differ from a conventional tag. Keep Enhanced measurement off as a further safeguard; do not use that setting as the private-route boundary. The production CSP permits the frame only from this app, with its own restricted policy. Verify actual GA4 delivery and consent behavior in a controlled deployment before enabling the measurement ID broadly; no live Google request is made by the tests.
